HOW TO

396 MEETING RECORDING은 회의를 녹음하면서 실시간으로 받아 적고, 회의가 끝나면 AI가 요약·정리해주는 무료 회의록 도구예요.

처음 한 번만 준비하면, 다음부터는 참가자 입력 → MEETING START → MEETING FINISH로 끝나요.

STEP 1Chrome으로 접속노트북 Chrome 브라우저
STEP 2API 키 넣기처음 한 번만 · 무료
STEP 3회의 녹음최대 2시간 이상
STEP 4정리 & PDF수정 후 저장

1. 권장 사양

특별한 장비는 필요 없어요. 다만 2시간 회의를 끊김 없이 받아 적으려면 아래 조건을 맞춰주세요.

항목권장설명
브라우저필수 Google Chrome (최신 버전)실시간 한국어 받아쓰기는 Chrome에서 가장 안정적이에요. Microsoft Edge도 대부분 동작하지만, Safari·Firefox·모바일 브라우저는 권장하지 않아요.
컴퓨터Mac 또는 Windows 노트북·데스크톱최근 5년 이내 출시 제품이면 충분해요. 메모리(RAM) 8GB 이상 권장.
인터넷필수 안정적인 Wi-Fi 또는 유선받아쓰기와 요약 모두 Google 서버를 거쳐요. 속도보다 끊기지 않는 것이 중요해요.
마이크내장 마이크 가능 · 외장 마이크 추천4명 이하 작은 회의는 노트북 내장 마이크로 충분해요. 회의실이 넓거나 6명 이상이면 USB 회의용 마이크를 테이블 가운데에 두세요.
전원충전기 연결2시간 녹음 중 배터리가 꺼지면 녹음이 멈춰요.
저장 공간여유 100MB 이상원본 녹음 파일은 2시간 기준 약 30MB예요.
💡 자리 배치 팁 마이크와 말하는 사람 사이는 1~3m가 좋아요. 노트북 키보드를 치거나 컵을 내려놓는 소리가 마이크 바로 옆에서 나지 않게 해주세요.

2. API 키 발급하기 (처음 한 번)

회의 요약은 Google의 AI(Gemini)를 무료로 사용해요. 이를 위해 내 Google 계정으로 "API 키"라는 비밀번호 같은 문자열을 한 번 만들어야 해요. 카드 등록은 필요 없어요.

  1. Google AI Studio 접속

    Chrome에서 aistudio.google.com/apikey 로 들어가요.

  2. Google 계정으로 로그인

    평소 쓰는 Gmail 계정으로 로그인해요. 회사 Google Workspace 계정은 관리자가 막아뒀을 수 있으니, 안 되면 개인 Gmail로 시도하세요.

  3. 이용 약관 동의

    처음 접속하면 약관 동의 창이 떠요. 내용을 확인하고 동의해요.

  4. API 키 만들기

    Create API key (또는 API 키 만들기) 버튼을 눌러요.

    프로젝트를 고르라고 하면 기본으로 제시되는 프로젝트를 선택하거나 새 프로젝트를 만들면 돼요. 이름은 아무거나 괜찮아요.

  5. 키 복사

    AIza로 시작하는 긴 문자열이 생겨요. 오른쪽 복사 버튼으로 전체를 복사해요. 앞뒤가 잘리면 동작하지 않아요.

  6. 396 MEETING RECORDING에 붙여넣기

    녹음 페이지 오른쪽 위 ⚙︎ 설정을 누르고 Gemini API 키 칸에 붙여넣어요 (Cmd+V / Ctrl+V).

  7. 모델 칸은 비워두기

    비워두면 지금 쓸 수 있는 무료 모델을 자동으로 찾아요. Google이 모델을 바꿔도 알아서 따라가요.

  8. 연결 테스트 → 저장

    연결 테스트를 눌러 ✓ 연결됐어요!가 뜨면 저장을 눌러요. 최대 1분쯤 걸릴 수 있어요.

    ✕가 뜨면 아래 7. 오류 해결에서 같은 문구를 찾아보세요.

⚠︎ 키는 비밀번호처럼 API 키를 단톡방·메일·문서에 올리지 마세요. 다른 사람이 쓰면 내 무료 사용량이 줄어들어요. 키가 노출됐다면 AI Studio의 API 키 목록에서 해당 키를 삭제하고 새로 만들면 돼요.
💡 노트북마다 한 번씩 키는 서버가 아니라 지금 쓰는 브라우저 안에만 저장돼요. 그래서 다른 노트북, 다른 브라우저, 시크릿 창에서는 설정에 다시 넣어야 해요. 같은 키를 여러 노트북에 넣어도 괜찮아요.

3. 마이크 연결 확인하기

MEETING START를 누르면 마이크를 자동으로 확인해요. 그래도 회의 전에 아래를 한 번 점검해두면 안심이에요.

① 컴퓨터가 마이크를 인식하는지

🍎 Mac

  • 시스템 설정 → 사운드 → 입력에서 사용할 마이크를 선택해요.
  • 말을 하면 입력 레벨 막대가 움직이는지 확인해요.
  • 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 Google Chrome이 켜져 있어야 해요.

🪟 Windows

  • 설정 → 시스템 → 소리 → 입력에서 사용할 마이크를 선택해요.
  • 말을 하면 입력 볼륨 막대가 움직이는지 확인해요.
  • 설정 → 개인 정보 및 보안 → 마이크에서 마이크 액세스와 데스크톱 앱 액세스가 켜져 있어야 해요.

② Chrome이 마이크를 쓸 수 있는지

  • 처음 MEETING START를 누르면 "마이크 사용" 허락 창이 떠요. 허용을 눌러요.
  • 실수로 차단했다면: 주소창 왼쪽 자물쇠(또는 설정) 아이콘 → 마이크 → 허용으로 바꾸고 새로고침해요.
  • 외장 마이크를 쓰려면 Chrome 주소창에 chrome://settings/content/microphone 을 입력해 기본 마이크를 선택할 수 있어요.

③ 녹음 중 확인

  • 녹음 중에는 타이머 아래 초록색 막대가 말소리에 맞춰 움직여요. 움직이지 않으면 마이크 입력이 없는 거예요.
  • 그 아래 상자에 받아쓴 문장이 실시간으로 나타나요.
  • 마이크 선이 빠지면 빨간 경고 문구가 떠요.
⚠︎ 다른 프로그램과 동시 사용 Zoom, Teams, 음성 녹음 앱이 마이크를 쓰고 있으면 "다른 프로그램이 마이크를 사용 중"이라는 오류가 날 수 있어요. 해당 프로그램을 종료하고 다시 시도하세요.

4. 회의 녹음하기

  1. 오늘의 참가자 입력

    이름을 쓰고 Enter 또는 쉼표(,)를 누르면 추가돼요. 1명 이상 적어야 시작할 수 있어요.

    참가자 이름은 요약할 때 사람 이름을 정확하게 바로잡는 데 쓰여요. 지난 회의 명단은 다음에도 남아 있어요.

  2. MEETING START

    마이크 확인이 끝나면 GIROGI가 안경을 쓰고 받아 적기 시작해요.

  3. 회의 진행

    평소처럼 말하면 돼요. 원두 이름, 농장 이름처럼 낯선 단어는 ⚙︎ 설정 → 추가 용어에 미리 적어두면 요약이 더 정확해져요.

  4. MEETING FINISH

    "정리중..."이 뜨고 AI가 요약을 만들어요. 2시간 회의는 1~3분쯤 걸릴 수 있어요.

⚠︎ 녹음 중에는 이것만 지켜주세요
  • 탭을 닫거나 새로고침하지 마세요. 받아쓴 글은 자동 저장되지만 원본 녹음 파일은 사라져요.
  • 노트북 덮개를 닫지 마세요. 잠자기 모드가 되면 녹음이 멈춰요. (화면 꺼짐은 자동으로 막아둬요)
  • 녹음 탭을 화면에 띄워두는 걸 권장해요. 다른 탭으로 오래 옮겨가면 Chrome이 받아쓰기를 늦추는 경우가 있어요.
💡 창이 실수로 닫혔다면 다시 접속하면 "지난번에 정리되지 않은 녹음 기록이 있어요"가 떠요. 이어서 정리하기를 누르면 그때까지 받아쓴 내용으로 요약해요.

5. 정리 · 수정 · PDF 저장

기능사용 방법
탭요약(AI 정리) · 메모(자유 메모) · 받아쓰기(시간이 표시된 원문)
수정제목·요약·메모·받아쓰기 어디든 클릭하면 바로 고칠 수 있어요. Backspace로 지우고 새로 쓰면 돼요. 목록에서 Enter를 누르면 항목이 추가돼요. 수정 내용은 자동 저장돼요.
다시 요약요약이 마음에 들지 않거나 실패했을 때 눌러요. 메모 탭 내용은 그대로 유지돼요. 요약 탭에서 직접 고친 내용은 새 요약으로 바뀌니 주의하세요.
PDF 추출요약과 메모를 A4 PDF로 다운로드해요. 받아쓰기 포함에 체크하면 원문도 함께 들어가요.
녹음 파일 저장원본 음성 파일(.webm)을 다운로드해요. 페이지를 새로고침하기 전에만 받을 수 있어요.
새 회의현재 문서를 지우고 처음 화면으로 돌아가요. 먼저 PDF로 저장해두세요.

6. 무료 버전의 제한과 주의사항

이 도구는 유료 서버 없이 무료 서비스들을 연결해 만들었어요. 그래서 아래 같은 한계가 있어요. 대부분은 잠시 기다리면 해결돼요.

AI 요약 (Google Gemini 무료 등급)

  • 사용 횟수 제한 — 분당·하루 요청 횟수 제한이 있고, Google이 수시로 기준을 바꿔요. 이 도구는 회의 1번에 요청 1번(실패 시 몇 번 재시도)만 써서, 하루 몇 번의 회의는 충분해요. 현재 한도는 AI Studio의 사용량 메뉴에서 확인할 수 있어요.
  • 혼잡 시간 지연 — 무료 사용자는 유료 사용자보다 뒤로 밀려요. "서버가 바빠요", "응답하지 않았어요"가 뜨면 자동으로 다른 무료 모델로 바꿔 재시도해요. 그래도 실패하면 1~2분 뒤 다시 요약을 눌러주세요. 받아쓴 내용은 사라지지 않아요.
  • 모델 변경 — Google은 무료 모델을 주기적으로 바꾸거나 종료해요. 모델 칸을 비워두면 자동으로 따라가요.
  • 회의 길이 — 2시간 분량 받아쓰기(대략 A4 30~40장)는 한 번에 요약할 수 있어요. 3시간 이상이면 요약이 덜 자세해질 수 있으니 회의를 나눠 녹음하는 걸 권장해요.
⚠︎ 개인정보 주의 Google 정책상 무료 등급에 보낸 내용은 Google이 서비스 개선에 활용할 수 있어요. 인사·계약·고객 개인정보처럼 민감한 내용이 오가는 회의에는 사용하지 않는 걸 권장해요.

실시간 받아쓰기 (Chrome 음성 인식)

  • 인터넷 필요 — 음성은 Google 서버에서 글자로 바뀌어요. 인터넷이 끊기면 받아쓰기가 잠시 멈추고, 다시 연결되면 자동으로 이어져요. 그동안에도 원본 녹음은 계속돼요.
  • 약 1분마다 자동 재연결 — Chrome은 받아쓰기를 일정 시간마다 끊는데, 이 도구가 바로 다시 연결해요. 이 순간 한두 단어가 빠질 수 있어요.
  • 정확도 — 여러 사람이 동시에 말하거나, 마이크에서 멀거나, 주변 소음이 크면 정확도가 떨어져요. 커피 전문 용어는 요약 단계에서 AI가 용어집을 참고해 바로잡아요.
  • 화자 구분 없음 — 누가 말했는지는 구분하지 못해요. 중요한 결정은 "○○님이 맡기로 했어요"처럼 이름을 말로 남기면 요약에 반영돼요.

저장 공간

  • 문서와 받아쓰기는 지금 쓰는 브라우저에만 저장되고, 한 번에 회의 1개만 보관해요. 다른 노트북에서는 보이지 않아요.
  • 브라우저 기록·쿠키를 지우거나 시크릿 창을 닫으면 저장된 문서도 지워져요.
  • 원본 녹음 파일은 저장되지 않고 메모리에만 있어요. 필요하면 회의 직후 녹음 파일 저장으로 받아두세요.
  • 결과는 PDF로 저장하는 것이 가장 안전해요.

7. 오류 해결

화면에 뜬 문구로 찾아보세요.

화면에 뜬 문구원인해결 방법
연결된 마이크가 없어요마이크 미연결마이크를 연결하고 3. 마이크 확인하기를 따라 점검해요.
마이크 권한이 거부되었어요Chrome 또는 OS에서 차단주소창 자물쇠 → 마이크 → 허용, 그리고 OS 마이크 설정에서 Chrome을 켜요.
다른 프로그램이 마이크를 사용 중Zoom 등과 충돌다른 프로그램을 종료하고 다시 시도해요.
한국어 실시간 받아쓰기를 지원하지 않아요Chrome이 아닌 브라우저데스크톱 Chrome으로 열어요.
API 키가 올바르지 않아요키 일부만 복사됨, 오타, 삭제된 키AI Studio에서 키 전체를 다시 복사해 붙여넣어요. 안 되면 새 키를 만들어요.
이 키로는 Gemini를 쓸 수 없어요키에 사용 제한이 걸림, 회사 계정 정책개인 Gmail로 AI Studio에서 새 키를 만들어요.
Google 서버가 잠시 바빠요무료 서버 혼잡 (503)자동으로 다른 모델로 재시도해요. 그래도 뜨면 1~2분 뒤 다시 요약.
무료 사용량을 잠시 초과했어요분당/하루 한도 초과 (429)1~2분 뒤 다시 시도해요. 계속되면 하루 한도이니 다음 날 시도해요. 받아쓰기 원문은 남아 있어요.
…초 동안 응답하지 않았어요서버 지연 또는 네트워크 차단잠시 뒤 재시도해요. 계속되면 회사 Wi-Fi·VPN·광고 차단 확장 프로그램이 막는 경우가 많아요. 휴대폰 핫스팟으로 시험해보세요.
Google 서버에 연결하지 못했어요인터넷 끊김, 광고 차단인터넷 연결을 확인하고 광고 차단 확장 프로그램을 이 사이트에서 꺼요.

8. 자주 묻는 질문

정말 무료인가요?
네. 받아쓰기는 Chrome에 내장된 기능, 요약은 Google Gemini 무료 등급, 사이트는 GitHub Pages 무료 호스팅을 써요. AI Studio에서 직접 결제 정보를 등록하고 유료 등급으로 바꾸지 않는 한 요금이 나가지 않아요.
휴대폰이나 태블릿에서도 되나요?
화면은 열리지만 권장하지 않아요. 모바일 브라우저는 화면이 꺼지거나 다른 앱으로 넘어가면 녹음과 받아쓰기가 멈춰요. 노트북 Chrome을 사용해주세요.
2시간보다 길게 녹음해도 되나요?
받아쓰기는 계속 이어져요. 다만 3시간이 넘으면 요약이 덜 자세해지고 무료 서버에서 실패할 확률이 높아져요. 중간에 FINISH로 한 번 정리하고 새로 시작하는 걸 권장해요.
회의 내용이 다른 사람에게 보이나요?
아니요. 이 사이트에는 회의 내용을 모아두는 서버가 없어요. 문서는 내 브라우저에만 저장돼요. 다만 받아쓰기와 요약을 위해 음성과 글이 Google 서버로 전송되고, 무료 등급은 Google이 서비스 개선에 활용할 수 있어요.
요약이 실제 회의 내용과 달라요.
AI는 받아쓴 글을 바탕으로 요약하기 때문에, 받아쓰기가 틀리면 요약도 틀릴 수 있어요. 받아쓰기 탭에서 원문을 확인하고 요약을 직접 고쳐주세요. 자주 틀리는 원두·사람 이름은 설정의 추가 용어에 적어두면 좋아요.
지난 회의록을 다시 볼 수 있나요?
한 번에 최신 회의 1개만 보관돼요. 지난 회의록은 PDF로 저장해서 보관해주세요.
